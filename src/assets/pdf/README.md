# PDF User Guide

## Place your PDF guide here

**File name:** `design-qc-user-guide.pdf`

**Location:** `src/assets/pdf/design-qc-user-guide.pdf`

## What to include in your PDF guide:

1. **App Overview & Purpose**
   - What Design QC does
   - Key features and benefits

2. **Prerequisites & Setup**
   - Required software/tools
   - System requirements
   - Installation steps

3. **Account Setup**
   - How to register
   - How to login
   - Initial configuration

4. **Core Features Walkthrough**
   - Document upload process
   - Quality checking workflow
   - Results interpretation

5. **Troubleshooting**
   - Common issues and solutions
   - Support contact information

6. **Best Practices**
   - Tips for optimal usage
   - Workflow recommendations

## File Requirements:
- **Format:** PDF
- **Size:** Keep under 10MB for optimal download experience
- **Language:** English (or your preferred language)
- **Accessibility:** Ensure text is selectable and readable

Once you place your PDF file here, the "Download User Guide" button on the login page will automatically work!
