Rule 7 - Bollard Distance Analysis

Rule Description

This rule analyzes the distances between adjacent bollards in the model. It identifies bollards within the "Specialty Equipment" category, specifically "TS_Square Bollard" family elements, and measures face-to-face distances between consecutive neighbors along horizontal and vertical lines.

Category

Specialty Equipment

Analysis Parameters

Pairing Mode: Chain Adjacency
Horizontal Overlap: 5 mm minimum
Vertical Overlap: 5 mm minimum
Line Tolerance: 3 mm

Expected Output

  • Console log with detailed analysis results
  • Distance measurements in both model units and millimeters
  • Face-to-face distances using both AABB and raycast methods
  • Summary of directed pairs and unique pairs found
